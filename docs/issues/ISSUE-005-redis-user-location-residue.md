# [ISSUE-005] 퇴장한 유저 위치 데이터 잔류

**발생 시점:** Redis 연동 구현  
**분류:** Redis

## 증상

- 앱을 종료하거나 반경 밖으로 이동한 유저의 데이터가 Redis에 계속 남음
- `GEOSEARCH` 결과에 실제로 근처에 없는 유저가 포함됨

## 원인

- Redis Geospatial은 TTL을 키 단위로만 설정할 수 있고, 멤버(유저) 단위 만료 기능이 없음
- 앱 종료나 이동 시 명시적으로 삭제하지 않으면 데이터가 영구 잔류

## 원인 흐름

```
유저 앱 종료 또는 반경 이탈
          ↓
Redis에 삭제 요청 없음
          ↓
GEOSEARCH 결과에 이탈한 유저 계속 포함
```

## 해결책

위치 데이터 저장 시 **TTL 설정 또는 명시적 삭제 로직**을 반드시 구현한다.

- 마지막 위치 전송 시각 기준 N초 이내 갱신이 없으면 삭제
- 또는 앱 종료 / 로그아웃 이벤트 시 `ZREM user:location user_id` 호출

```bash
ZREM user:location "user_1"
```
