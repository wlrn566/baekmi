# [ISSUE-002] Docker 컨테이너 ↔ 로컬 포트 충돌

**발생 시점:** NestJS 백엔드 구축  
**분류:** Docker

## 증상

- 로컬 코드 변경을 컨테이너에 반영하는 watch 기능 적용 시
- 컨테이너 포트와 로컬 백엔드 포트가 동일해 동시에 실행 불가

## 원인

- 로컬에서 직접 실행 중인 백엔드와 컨테이너가 동일한 포트를 사용하려 해 충돌 발생

## 원인 흐름

```
로컬 백엔드 실행 (PORT=3000)
          ↓
Docker 컨테이너도 동일 포트(3000) 사용 시도
          ↓
포트 이미 점유됨 → 컨테이너 기동 실패
```

## 해결책

**외부 포트는 다르게, 내부 포트는 동일하게** 매핑한다.

- 내부 포트를 동일하게 유지해야 컨테이너 간 연동 포트가 로컬 백엔드와 일치한다.

```yaml
ports:
  - "4001:${PORT}"
```
